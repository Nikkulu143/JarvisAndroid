# Jarvis Android v1

A starter Android voice-assistant project for POCO F3 GT.

Current starter features:
- Voice input
- Telugu/English-friendly Indian English speech recognition
- Text-to-speech response
- Runtime permissions
- WhatsApp notification listener hook

Important:
- Do NOT put an OpenAI API key inside the APK/source code.
- Full hands-free wake word, speaker verification, call screening/answering, and WhatsApp auto-reply need additional Android services/APIs and device-specific testing.
- Android/WhatsApp may restrict some automation even when permissions are granted.

Build with Android Studio or a compatible cloud Android build environment.
